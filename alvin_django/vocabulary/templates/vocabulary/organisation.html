En viktig del av arbetet är att söka efter och kontrollera om en befintlig namnform redan finns som en länkbar enhet och i så fall länka till den.' %}

{% translate 'En organisation definieras som ett företag, institution eller en grupp av personer och/eller organisationer som agerar, eller kan agera, som en enhet.' %}

{% translate 'Exempel på organisationer är föreningar, företag, ideella organisationer, regeringar, statliga myndigheter, kommuner, projekt, musikgrupper, trossamfund och konferenser.' %}

{% translate 'Tillfälliga evenemang såsom idrottstävlingar, utställningar, expeditioner, mässor och festivaler, liksom farkoster såsom fartyg och rymdfarkoster, betraktas också som organisationer.' %}

{% translate 'Auktoritetsinformation' %}

{% translate 'Minst en föredragen namnform måste anges för webbsidorna på engelska, svenska eller norska. Detta språk anger vilken språkversion av webbsidan det gäller, snarare än språket för själva namnformen. Om endast en namnform anges kommer den att visas på alla språkversioner av webbsidorna.' %}

{% translate 'För utländska organisationer som saknar en vedertagen namnform på något av visningsspråken, välj namnformen från det aktuella landet tillsammans med visningsspråket.' %}

{% translate 'Vissa namn har en språkspecifik form. Detta gäller till exempel internationella organisationer, äldre organisationer samt religiösa ordnar och samfund.' %}

{% translate 'Det föredragna namnet är det namn som organisationen är mest känd under. För att fastställa detta, använd följande källor (i prioritetsordning):' %}

  1. {% translate 'föredragna informationskällor i material som är kopplat till organisationen, såsom titelsidor' %}
  2. {% translate 'andra formella uppgifter som förekommer i material kopplat till organisationen' %}
  3. {% translate 'andra källor (inklusive referenskällor såsom VIAF eller Wikipedia)' %}

{% translate 'När en organisation byter namn och namnbytet kan anses vara av betydelse, ska en ny post skapas för det nya namnet. När en organisation uppträder under ett ändrat namn har det sannolikt även skett förändringar inom organisationen eller dess verksamhet. Om en organisation har genomgått en omfattande omorganisering, slagits samman med andra, delats upp i flera enheter, eller om verksamhetens inriktning har förändrats väsentligt, bör organisationen betraktas som ny.' %}

{% translate 'Registrera i varje post, både den gamla och nya, en relaterad organisation av typen tidigare/senare, en historisk notering som förklarar relationerna, samt start- och sluttid om uppgifterna finns tillgängliga.' %}

{% translate 'Det är möjligt, men inte obligatoriskt, att ange den auktoriserade formen på alla tre visningsspråk i de fall då dessa skiljer sig åt, t.ex. Jesuits/Jesuittordenen/Jesuitorden.' %}

{% translate 'Den föredragna namnformen måste vara skriven med latinska bokstäver.' %}

{% translate 'Ange inte alternativa namnformer i det här avsnittet.' %}
