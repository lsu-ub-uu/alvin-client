Linked Art

Linked Art {% translate 'är en applikationsprofil baserad på relevanta internationella standarder som kan användas för att beskriva kulturarvsresurser med fokus på konst och museirelaterad verksamhet.' %}

{% translate 'Den definierar gemensamma mönster och termer för att säkerställa att resulterande data enkelt kan återanvändas. I enlighet med etablerad praxis inom området utgår modellen från följande grundläggande standarder:' %}

  1. CIDOC-CRM {% translate 'som den centrala konceptuella modellen. Linked Art använder en förenklad delmängd (CIDOC-CRM 7.1.3) för att säkerställa konsekvens och begriplighet.' %}
  2. Getty Vocabularies {% translate 'som centrala källor för identifiering av domänspecifik terminologi.' %}

{% translate 'Modellen serialiseras som JSON-LD (JavaScript Object Notation for Linked Data) som är ett lättviktigt dataformat som används för att strukturera information på webben.' %}

{% translate 'En bibliografisk post i Alvin beskriver antingen ett fysiskt objekt (som en bok) eller en samling av objekt (som ett arkiv). Fysiska objekt mappas mot typen HumanMadeObject och samlingar mot typen Set.' %}

{% translate 'Alla poster innehåller de obligatoriska egenskaperna @context, id, type och _label samt identified_by som innehåller det primära namnet (huvudtitel för bibliografiska poster och verk eller den auktoriserade namnformen för personer, organisationer, platser och arkivinstitutioner), eventuella alternativa namn, postens unika id i Alvin samt i förekommande fall externa identifierare som t.ex. VIAF eller ISSN.' %}

{% translate 'Poster av typen HumanMadeObject eller Set kan även innehålla egenskaperna classified_as (kontrollerade former för resurstyp eller genre samt olika typer av ämnesord), current_owner (ägaren eller den som tillhandahåller objektet/samlingen), current_location (fysisk placering), member_of (underordnad samling), made_of (material), referred_to_by (alla typer av textbeskrivningar som anmärkningar, sammanfattning, litteraturreferenser etc.), subject_of (länkar till andra relaterade resurser) samt tillkomstinformation i produced_by för fysiska objekt och created_by för samlingar. {% translate 'För auktoritetsposter innehåller de olika typerna förutom de obligatoriska egenskaperna och identified_by även classified_as och referred_to_by (alla typer utom Place), part_of och defined_by (Place), born och died (Person), formed_by, dissolved_by och contact_point (Group), subject_of (Person och Group) samt tillkomstinformation för LinguisticObject i created_by.' %}

IIIF Change Discovery API

IIIF Change Discovery API 1.0 {% translate 'används i Alvin för att underlätta identifieringen av ändringar i metadata för de olika huvudtyperna.' %}

Activity Streams {% translate 'används för att beskriva dessa ändringar genom en OrderedCollection (en sammankopplad uppsättning sidor) där varje underliggande OrderedCollectionPage innehåller en lista över när en post senast ändrades.' %}

{% translate 'OrderedCollection fungerar som en navigeringsmässig utgångspunkt för att upptäcka ändringar och innehåller en referens till den sista OrderedCollectionPage i samlingen. Observera att API-specifikationen rekommenderar att bearbetningen påbörjas med den sista sidan.' %}
